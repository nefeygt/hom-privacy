# hom-privacy

The privacy policy for **HOM**, a mobile game published on Google Play as `com.nefeygt.hom`.

It is served by GitHub Pages at <https://nefeygt.github.io/hom-privacy/>, which is the URL linked
from the Play Store listing.

`index.md` is the page. The same text is kept in the game's own repository at
`docs/privacy-policy.md`, which is where edits should be made first so the two stay in step.
